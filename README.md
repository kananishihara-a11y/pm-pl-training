# PM/PL Training

PM/PL育成研修の学習成果物

## 目的

スクラッチ開発プロジェクトに必要な基礎知識を身につけ、
PM/PLとして開発チームと会話できるようになる。

## 学習内容

- Markdown
- Backlog
- スクラッチ開発プロジェクト全体像
- Git / GitHub
- Webシステム
- システム開発プロセス
- 設計書
- PM/PL実践

## 現在の学習状況

Git / GitHub・ソースコード管理基礎を学習中。

## Backlog

Backlogを利用して、自分の研修課題・期限・進捗を管理する。

毎日の学習開始時にBacklogを確認し、
学習終了後に実施内容・理解したこと・課題を記録する。
